# Cloud Provider Comparison

A comparison of core infrastructure services offered by the three leading
public cloud providers.

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines (Azure VMs) | Compute Engine |
| Storage | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) / Azure RBAC | Google Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS is generally recognized as offering the broadest range of services, since
it was the first major public cloud provider and has continuously expanded
into hundreds of specialized services covering compute, storage, databases,
AI/ML, IoT, and more. Its long head start gave it more time to build out a
wide ecosystem compared to Azure and GCP.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**
Microsoft Azure would be the best fit, because it integrates tightly with
Microsoft's existing ecosystem — Active Directory, Windows Server, Microsoft
365, and .NET applications. Organizations already using these tools benefit
from smoother identity management and licensing integration.

**3. Which platform is widely recognized for AI, Machine Learning, and Kubernetes services?**
Google Cloud Platform is widely recognized in these areas. GCP created
Kubernetes and offers Google Kubernetes Engine (GKE) as a leading managed
Kubernetes service, and it's known for strong AI/ML tools like Vertex AI,
built on Google's deep research background in machine learning.

**4. What similarities did you observe among the three cloud providers?**
All three providers offer equivalent core categories of service — compute,
storage, networking, and identity/access management — even though they use
different product names. Each also follows a pay-as-you-go pricing model,
provides global data center regions, and offers both a web console and
command-line tools for managing resources.
