 Mission 1: Welcome to the Cloud

   ## Mission Overview
   This activity covers onboarding into a Linux cloud environment using
   KillerCoda, exploring the system, organizing files, and building a
   GitHub-based Cloud Computing Portfolio.

   ## Objectives
   - Access a cloud-based Linux environment using KillerCoda
   - Explore and navigate the Linux operating system
   - Gather basic system information
   - Organize files and directories using Linux commands
   - Create and maintain a professional GitHub repository
   - Document technical work using Markdown

   ## Activities Performed
   - Created a new user (gcabanizas) with sudo privileges and logged in
   - Checked Linux distribution, kernel version, CPU, memory, and disk space
   - Created a folder structure (Documents, Notes, Reports, Screenshots)
   - Created and viewed markdown files (about-me.md, system-information.md)
   - Built and organized a GitHub portfolio repository

   ## Linux Commands Used
   | Command | Purpose |
   |---|---|
   | `sudo adduser` | Create a new user |
   | `usermod -aG sudo` | Grant sudo privileges |
   | `su -` | Switch user |
   | `whoami` | Show current username |
   | `pwd` | Show current directory |
   | `hostname` | Show system hostname |
   | `lsb_release -a` | Show Linux distribution |
   | `uname -r` | Show kernel version |
   | `lscpu` | Show CPU info |
   | `free -h` | Show memory usage |
   | `df -h` | Show disk space |
   | `mkdir` | Create directories |
   | `nano` | Create/edit files |
   | `cat` | View file contents |

   ## Skills Learned
   Basic Linux navigation and user management, system information
   gathering, file/directory organization, Markdown documentation,
   and GitHub repository management.
