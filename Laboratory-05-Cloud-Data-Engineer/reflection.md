# Mission Reflection

### 1. Why is Object Storage better suited for millions of photos than a traditional Block Storage hard drive?

Object Storage is better for millions of photos because it is designed to store many files such as pictures, videos, and backups. It can organize files using buckets and objects, making them easier to manage. This makes it useful for applications that need to store a large number of photos.

### 2. How did Docker make it easier to deploy MinIO?

Docker made it easier to deploy MinIO because I only needed to run a Docker command to create the MinIO container. I did not have to manually install and configure everything. I also learned how to fix errors when my commands did not work.

### 3. What is a bucket in cloud storage?

A bucket is a container used to store files or objects in cloud storage. In this activity, I created a bucket called `client-photos`. I uploaded a sample file to it to check if the MinIO storage was working correctly.

### 4. How do large enterprise companies make sure Object Storage data is not lost if a physical server crashes?

Large companies protect their data by keeping multiple copies of files on different servers or locations. They also use backups and data replication. If one physical server crashes, another copy can still be available. This helps prevent important data from being lost.

### 5. How is your confidence with the Linux command line growing?

My confidence with the Linux command line is improving. In this activity, I used commands like `docker run` and `docker ps` to deploy and check MinIO. I made some typing mistakes, but I learned how to correct them. This activity made me more comfortable using the terminal.
